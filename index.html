Dados e backup

Os dados ficam salvos neste celular, neste navegador. Não limpe os dados do navegador e faça o backup toda semana: no celular, o botão abre o menu de compartilhar, e você pode enviar o arquivo para o seu WhatsApp.

Os dados de exemplo servem só para testar os indicadores e podem ser removidos sem afetar os lançamentos reais.
